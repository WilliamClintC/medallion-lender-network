# Medallion lender network

Interactive network of who held NYC taxi medallion loans, and where they moved, 2000 to 2025.
Open the page: https://williamclintc.github.io/medallion-lender-network/

- Nodes are lender families at fixed positions; node area is medallions held at year end.
- Arrows are medallions moved in the year: sale (assignment), refinancing, new loan, exit, merger successor.
- **No dollar amounts.** Every number is a count of medallions, not loan dollars; UCC filings record no loan principal.
- Holder of record from New York Department of State UCC filings (via Lexis). Work in progress, not a publication.
